# Maestro's Beats: Conquer Classic — 체험판

클래식 명곡을 당신의 비트로 깨우는 스토리 리듬게임의 Windows 체험판입니다. 이 저장소에는 배포 파일만 있습니다.

## 다운로드

**[최신 체험판 받기 (Windows 10/11, 64-bit)](https://github.com/yunch0315/maestros-beats-demo/releases/latest)**

## 설치

1. `MaestrosBeats-…-win-x64-setup.exe`를 실행합니다.
2. Windows SmartScreen 경고가 나오면 **추가 정보 → 실행**을 누릅니다. 아직 코드 서명 전 빌드라서 나오는 경고입니다.
3. 설치 폴더를 고르면 바탕화면과 시작 메뉴에 바로가기가 생깁니다.

## 조작

| 화면 | 키 |
|---|---|
| 대사 | 클릭 · Space · Enter 진행, Esc 건너뛰기 |
| 게임 중 | Esc 일시정지, F11 또는 Alt+Enter 전체 화면 |

노트가 소리와 어긋나면 설정 → 싱크 보정 테스트로 맞추세요. 진행 기록은 게임을 제거해도 남습니다.

## 업데이트

1.0.2부터는 게임을 켤 때 새 버전을 자동으로 확인하고, 있으면 내려받아 설치한 뒤 다시 시작합니다. 1.0.1 이하를 쓰고 있다면 위 링크에서 최신 버전을 한 번만 직접 설치해 주세요.

## 문제가 생기면

- **게임 화면이 멈췄을 때**: 바로가기로 게임을 한 번 더 실행하면 몇 초 안에 다시 불러옵니다. 그대로 두어도 30초쯤 뒤 "다시 불러오기" 창이 뜹니다. 진행 상황은 저장되어 있습니다.
- **실행해도 아무 반응이 없을 때**: 이전 게임이 완전히 멈춰 남아 있는 경우입니다. 작업 관리자(Ctrl+Shift+Esc)에서 `Maestro's Beats`를 종료한 뒤 다시 실행하세요.
- 1.0.0에서는 게임을 껐다 켜면 진행이 사라지는 문제가 있었습니다. 1.0.1부터 고쳐졌습니다(1.0.0에서 쌓은 진행은 복구되지 않습니다).
